# 🥚 v1.6.0 · 一条命令，把「免费额度全家桶」装到本机

> **以前**：装完插件只是有了个显示器——WorkBuddy 网关、Qoder 网关、New API、密钥、渠道、模型，全都要自己配。
>
> **现在**：一条命令把三个后端装好、配置写好、服务拉起来，插件配置也自动生成。你只需要照着指引登录账号。

这次更新把「安装」从一个下午的折腾，压缩成一次下载 + 四次登录。

---

## ✨ 一条命令，三个服务

```powershell
git clone https://github.com/Yhx888/dsh-free-egg-credits.git
cd dsh-free-egg-credits
powershell -ExecutionPolicy Bypass -File .\install\windows.ps1
```

脚本会自动完成：

| 步骤 | 说明 |
|---|---|
| 📦 下载 | WorkBuddy2API、Qoder2API-Hub、New API 全部来自官方 release，带 SHA256 校验、断点续传、失败重试 |
| 🔧 配置 | 写 `config.json`、生成随机 `api_key` / Qoder 面板密码，端口默认 7863 / 8790 / 3001 |
| 🚀 启动 | 三个服务隐藏启动，只监听 `127.0.0.1`；生成 `start-stack` / `stop-stack` / `status` 三个脚本 |
| 📖 指引 | 生成《使用指引》：三个面板怎么登录、New API 怎么建渠道、DSH 怎么接 |
| 🧩 插件 | 生成 `dsh-snippets.yml` + `dsh-provider.yml`；检测到插件已安装时，自动把插件配置追加到 profile 的 `cordis.patch.yml`（带备份） |

默认安装到 `%LOCALAPPDATA%\FreeEggStack`，随时可以整体搬走（Qoder 用内置 Python，不依赖本机环境）。

> 想先看它会做什么？加 `-DryRun`。只缺一个网关？加 `-SkipQoder` 或 `-SkipNewApi`。
> 完整参数与目录结构见 [install/README.md](https://github.com/Yhx888/dsh-free-egg-credits/blob/main/install/README.md)。

## 🔑 装完只要四步登录

| 步骤 | 打开 | 做什么 |
|---|---|---|
| 1️⃣ | http://127.0.0.1:7863/panel/ | 输入安装器打印的密钥 → **添加账号** → 国内版微信扫码 / 国际版 Google、GitHub 授权 |
| 2️⃣ | http://127.0.0.1:8790/ | 输入安装器打印的密码 → **账号 → + 添加账号 (OAuth)** → 选择国内版 / 国际版完成授权 |
| 3️⃣ | http://127.0.0.1:3001/ | 初始化管理员 → **渠道**里添加 WorkBuddy / Qoder 两条（Base URL 分别指向 7863 / 8790）→ **令牌**里创建 `sk-...` |
| 4️⃣ | DSH | 安装本插件 → 把 `dsh-snippets.yml` 的插件段与 `dsh-provider.yml` 的 provider 段合并进 `cordis.patch.yml` → 重启 DSH |

DSH 侧边栏底部随即出现账号积分区块：余额、今日已用 / 上限、签到状态、当前消耗账号、每轮消耗，全部就位。

> 每个账号的登录都在官方页面完成，插件和安装器不会接触你的账号密码；凭证只落在本机（`auths/`、`accounts/`）。

## 🎁 你会得到

- **一个侧边栏看全部**：WorkBuddy / Qoder 各账号余额、今日预算（已用 / 上限 / 剩余 / 满额）、签到状态、当前消耗账号。
- **每一轮的花费**：会话累计与逐轮折算，悬停可看 token 与模型；缓存命中单独计价，不再把 57M 上下文乘混合单价高估数倍。
- **满额能救急**：Qoder 拥堵或额度用完，点一下 chip 切回 WorkBuddy 优先（需在 New API 配置管理员 token）。
- **后台自动签到**：两个网关自带调度器（WorkBuddy 09:00 / 21:00，Qoder 09:00 / 10:15 / 10:45 / 21:00），不依赖 DSH 是否打开。
- **可移植**：安装目录整体搬移不坏；`stop-stack.ps1` 只停本目录启动的进程，不误杀你已有的服务。

## 🛡️ 安全与边界

- 三个服务默认只监听 `127.0.0.1`，**不要映射到公网**；New API 的管理 token、面板密码、账号凭证都只在本机。
- 安装器只从本项目 README 列出的官方 GitHub / python.org 地址下载，全部做 SHA256 校验，不访问其它域名，也不收集遥测。
- 三个上游都是独立开源项目：WorkBuddy2API（MIT）、Qoder2API-Hub（MIT）、New API（AGPL-3.0）；安装器只下载官方 release 并启动，不修改它们的代码。
- 本项目与 WorkBuddy / Qoder / DeepSeek 官方无关；请只使用本人合法授权的账号，并遵守各自服务条款。

## ⚠️ 两个已知提示

1. **杀软误报**：安装器是「下载 + 解压 + 启动本地服务」的 PowerShell 脚本，部分国产杀软（如火绒）会启发式报
   `HEUR:TrojanDownloader/PS.NetLoader`。这是误报，把 `install/windows.ps1` 加入信任区即可；所有下载都有固定 SHA256。
2. **首次启动没数据是正常的**：WorkBuddy 面板在还没有账号时 `/healthz` 返回 503；先按指引登录账号即可。
