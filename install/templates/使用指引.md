## 1. WorkBuddy 网关（端口 {{WB_PORT}}）

**面板地址**：http://127.0.0.1:{{WB_PORT}}/panel/
**面板密钥**：{{WB_KEY}}（也写在 {{ROOT}}/workbuddy/config.json 的 api_key 字段）

登录步骤：

1. 浏览器打开面板地址，粘贴上面的密钥。
2. 点右上角 **添加账号**。
3. 选择账号类型：
   - **国内版（CN）**：微信扫码 / 手机号登录（腾讯 CodeBuddy 账号）。
   - **国际版（Global）**：Google / GitHub OAuth 登录。
4. 在打开的授权页完成登录，回到面板会自动检测授权结果：
   - 凭证落盘到 {{ROOT}}/workbuddy/auths/；
   - 热加载进池，不需要重启；
   - 国内版会自动跑一次首次签到，国际版会自动补地区 / 激活 / 领取 trial 加油包。
5. 有多个账号就重复第 2–4 步；面板会按余额、冷却、每日预算自动选号。

日常签到：网关自带后台调度器（默认每天 09:00 / 21:00 签到，另有活跃上报、token 保活等），不依赖 DSH 是否打开。插件打开界面时还会做一次幂等补签与状态核对。

## 2. Qoder 网关（端口 {{QODER_PORT}}）

**看板地址**：http://127.0.0.1:{{QODER_PORT}}/
**看板密码**：{{QODER_PW}}（也写在 {{ROOT}}/qoder/.panel-password）

登录步骤：

1. 浏览器打开看板地址，输入上面的密码（默认账号就是看板密码本身，不需要用户名）。
2. 进入 **账号** 页，点 **+ 添加账号 (OAuth)**。
3. 选择 **国内版（qoder.com.cn）** 或 **国际版（qoder.com）**，在浏览器完成授权。
4. 授权成功后账号会自动落盘到 {{ROOT}}/qoder/accounts/，无需重启。
5. 多账号重复第 2–4 步即可；网关会按模型自动选区、轮询、故障换号。

要点：

- Qoder 每日活动约 **10:00（UTC+8）** 刷新；网关调度器在 09:00 / 10:15 / 10:45 / 21:00 自动巡检并领取，不依赖 DSH 打开。
- 看板「设置」里可以改密码、生成 API Key、配置每日积分限额。
- 免费模型 Qwen3.8-Flash 不消耗积分，可直接用于兜底。

## 3. New API 聚合入口（端口 {{NEWAPI_PORT}}）

**控制台地址**：http://127.0.0.1:{{NEWAPI_PORT}}/

### 3.1 初始化

第一次打开会进入初始化向导：创建管理员账号（用户名 + 密码）。数据库是本地 SQLite，文件在 {{ROOT}}/newapi/one-api.db，请自己备份这个文件。

### 3.2 建两个渠道（把两个网关接进来）

进入 **渠道 → 添加渠道**，建两条：

| 字段 | WorkBuddy 渠道 | Qoder 渠道 |
|---|---|---|
| 名称 | WorkBuddy | Qoder |
| 类型 | OpenAI / OpenAI 兼容 | OpenAI / OpenAI 兼容 |
| Base URL | http://127.0.0.1:{{WB_PORT}}/v1 | http://127.0.0.1:{{QODER_PORT}}/v1 |
| 密钥 | {{WB_KEY}} | 看板「设置」生成的 Key；本机未配置 Key 时可留空 |
| 模型 | 以网关 /v1/models 为准，例如 deepseek-v4.1-flash | 例如 Qwen3.8-Flash |

保存后点每条渠道的 **测试**，确认可用。两个渠道的 id 会出现在渠道列表 / URL 里（如 /console/channel/1），后面插件「积分优先消耗」要用。

### 3.3 创建访问令牌

进入 **令牌 → 添加令牌**，创建后复制 sk-...。这是 DSH 调用 New API 用的 Key，不是网关密钥。

把 Key 填进 DSH 的环境变量 FREE_EGG_API_KEY（用户级环境变量），或在 llm-pi-ai 的 provider 配置里写 apiKey。然后用下面的命令验证：

    curl http://127.0.0.1:{{NEWAPI_PORT}}/v1/models -H "Authorization: Bearer <key>"

### 3.4 （可选）开启「积分优先消耗」切换

1. New API 控制台 → 个人设置 → **系统访问令牌**，生成管理员 access token。
2. 把 token 写进 {{ROOT}}/newapi/access-token（文件内容就是 token 本身，注意收紧文件权限）。
3. 把 dsh-snippets.yml 里 newApi 段的注释去掉，channels.workbuddy / channels.qoder 改成第 3.2 步的真实渠道 id。
4. 重启 DSH 后，设置页会出现「积分优先消耗」切换；侧边栏标题行也会有快捷 chip。

## 4. DSH 插件

### 4.1 安装插件

- **桌面端**：左侧 **插件 → 添加插件**，粘贴 https://github.com/Yhx888/dsh-free-egg-credits，安装后重启 DSH。
- **Web / CLI**：dsh plugin --profile web add github:Yhx888/dsh-free-egg-credits

### 4.2 写入配置

1. 打开 C:\Users\<你>\.dsh\profiles\<profile>\cordis.patch.yml。
2. 把 {{ROOT}}/dsh-snippets.yml 的第 1 段（- id: free-egg-credits）追加到文件末尾。
3. 把第 2 段（free-egg:）合并进现有 llm-pi-ai 条目的 providers: 下（如果已有 free-egg，只改 baseURL 并核对模型名）。
4. 重启 DSH。侧边栏底部应出现账号积分区块；设置页多出「Free Egg 积分」。

> 插件读取的是本机网关接口，密钥 / 面板密码 / New API token 都只在 DSH Host 进程内使用，不会下发浏览器。

## 6. 常见问题

**Q：端口被占用？**
A：用 -WbPort 17863 -QoderPort 18790 -NewApiPort 13001 重跑安装器（端口会写进配置和启动脚本）。或者先停掉占用端口的程序。

**Q：Qoder 没有内置 Python？**
A：安装器会自动下载 Python 3.12 embeddable 到 qoder/python/；如果下载失败，安装系统 Python 3.9+ 后重跑。

**Q：WorkBuddy 面板显示 503 / 没有账号？**
A：/healthz 在无可用账号时返回 503 是正常的；先在面板「添加账号」完成登录。

**Q：New API 渠道测试失败？**
A：确认两个网关已启动、Base URL 带 /v1、WorkBuddy 密钥与 workbuddy/config.json 的 api_key 一致；Qoder 若在看板设置了 API Key，要填同一个。

**Q：积分显示「—」？**
A：账号余额未知（上游退化账本）或还没完成首次拉取；点设置页刷新，或确认账号已登录。

**Q：怎么卸载？**
A：先跑 stop-stack.ps1，删除 HKCU Run 里的 FreeEggStack（如果注册过），再删除 {{ROOT}} 目录即可。删除前请自行备份 newapi/one-api.db 与账号目录。

## 7. 安全与合规

- 三个服务默认只监听 127.0.0.1；不要把端口映射到公网，也不要关掉 New API 的鉴权。
- 账号凭证、面板密码、New API token 都只保存在本机；不要提交到 Git、不要发给别人。
- 本项目是非官方自托管网关 + 展示插件，仅限本人合法授权的账号在私有环境使用；请遵守 WorkBuddy / Qoder / DeepSeek 各自的服务条款。
- 第三方组件的许可证：WorkBuddy2API（MIT）、Qoder2API-Hub（MIT）、New API（AGPL-3.0）。安装器只负责下载与启动，不修改它们的代码。
